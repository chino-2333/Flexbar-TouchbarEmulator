TouchbarEmulator 1.1.3 adds macOS 27 support with native 2170×60 Touch Bar capture and interactive buttons/sliders, without creating a virtual display.

- Capture runs in a nonactivating host below the desktop, at the outer edge of the display layout.
- Touch input is sent directly to Apple's service and does not move the desktop cursor or take focus.
- Display layout changes reposition the capture host. macOS 26 and earlier keep the native backend when selected by FlexDesigner.
- The bundled Apple XPC keeps its original Apple signature.

Known limitation: Mission Control and transitions involving fullscreen Spaces can briefly reveal the simulator host. This is the accepted tradeoff for avoiding a virtual display.

Validation includes native 2× pixel comparison, real button/slider callbacks, concurrent desktop mouse dragging, focus and cleanup, plus simulated multi-display and monitor attach/remove tests. Physical monitor combinations and all system visibility transitions are not exhaustively covered.

Install `com.chino.touchbaremulator.flexplugin` in FlexDesigner. A FlexDesigner build with macOS 27 Touch Bar bridge support is required on macOS 27.
